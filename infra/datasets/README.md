# infra/datasets — reproducible vendored-dataset sampling scripts

Every vendored sample under `modules/**/data/` that is *derived* from a larger
public dataset is produced by a committed, seeded script here (P2-D2 / R11), so
the sample can be regenerated byte-for-byte and audited against its source.

| Script | Produces | Source |
|--------|----------|--------|
| `make_california_sample.py` | `modules/04-classical-ml/data/california-housing-sample.csv` | scikit-learn `fetch_california_housing` (1990 US Census / StatLib; public domain) |
| `make_glove_sample.py` | `modules/06-vision-sequences/data/glove-50d-sample.csv` | Stanford GloVe `glove.6B.50d.txt` (Wikipedia 2014 + Gigaword 5; PDDL) — fetched by HTTP-range extraction of the single zip member from the official mirrors |

Run (from the repo root, in the CI notebook environment so library versions
match the pinned runtime):

```bash
python infra/datasets/make_california_sample.py
python infra/datasets/make_glove_sample.py
```

Both scripts are deterministic: re-running them must reproduce the committed
CSVs byte-for-byte (verified at review time with `cmp`). Ledger entries live in
`docs/ASSETS.md`.
