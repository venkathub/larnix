# Diagram font

Caveat variable font, unmodified, downloaded from the [Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/caveat) on 2026-10-12. Source filename: `Caveat[wght].ttf`; local filename: `Caveat.ttf`.

Copyright 2014 The Caveat Project Authors (https://github.com/googlefonts/caveat). Distributed under the SIL Open Font License 1.1; see [OFL.txt](OFL.txt). The static site serves this asset locally. Diagram paths, labels and lesson content are original Larnix work.

Patrick Hand Regular comes from https://github.com/google/fonts/tree/main/ofl/patrickhand and is based on Patrick Wagesreiter’s handwriting. Served locally for upright handwritten reading text. Licensed under the SIL Open Font License in `PatrickHand-OFL.txt`. Downloaded October 12, 2026.
