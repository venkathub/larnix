## Release and review limits

These changes are local until merged and published. The existing public classroom is not evidence for this branch. Local automated tests cover curriculum consistency, dependency order, declared delivery evidence, generated links, browser engines and the data lab's valid and invalid inputs. Browser checks verified the homepage, expanded M02 catalogue, pandas blueprint/download and eight-lesson M29 overview. The pandas plan had no horizontal overflow at a 390-pixel viewport and no captured console errors. The downloaded ZIP matched the built artifact byte for byte. These checks are not a complete accessibility audit.

The data lab was executed in a fresh Python 3.12.14 virtual environment with NumPy 2.3.5, pandas 2.3.3 and Matplotlib 3.10.7. Its four tests passed, totals matched the hand calculation (103), and all three injected data failures were rejected. The generated plot was visually inspected.

There has been no blinded beginner trial, no measured ten-minute comprehension study and no production deployment of the new exercises. The remaining narrative authoring, worked production solutions and reviewed nine-part acceptance evidence are open delivery work. This response closes the identified planning gaps and improves executable/data-status evidence; it does not declare the whole curriculum delivered.
