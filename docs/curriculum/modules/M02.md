# M02 — Software engineering for AI

[All modules](../INDEX.md) · [Learning path](../LEARNING_PATH.md) · [Source register](../SOURCES.md) · [Teaching design](../TEACHING_DESIGN.md)

**Status:** in_progress · **Depth:** core · **Track:** T1

**Entry prerequisites:** Entry module; see the readiness guide in the curriculum overview.

7 lesson specifications follow. Each lesson will use a concrete problem, prediction, interactive explanation, worked example, inline checks and failure investigation before production and interview practice. Follow the teaching design for accessibility and original visual treatment. Delivery status is stated per lesson; a preview is not a completed lab. Complete the evidence package for each exercise; live deployment is not required. Later lessons may introduce an additional cross-module prerequisite.

## Module outcomes

- Specify a small typed component that runs reproducibly outside a notebook.
- Separate transport failures from invalid application data.
- Design bounded concurrency and propagate cancellation through a request.
- Define atomic writes and tests for partial failure.
- Compute daily equipment costs with explicit shapes and verify that a vectorized result agrees with a loop.
- Join rentals and equipment rates without silently multiplying observations or dropping unknown equipment.
- Produce a reproducible dataset report whose plots expose missingness and unequal sample sizes.
