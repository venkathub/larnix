## M37-L01 — Prepare visual inputs

**Prerequisites:** [M05-L04](M05.md#m05-l04), [M11-L04](M11.md#m11-l04), [M25-L04](M25.md#m25-l04)

**Learning outcome:** Preserve task-relevant information through visual preprocessing.

**Topics:** image decoding; resizing; patches; resolution; crops; OCR; metadata.

**Study estimate:** 1–2 hours guided study + 2–4 hours exercise. These are learner-effort estimates, not an implementation schedule.

### Primary readings

- [VISION: Hugging Face image text to text](https://huggingface.co/docs/transformers/main/en/tasks/image_text_to_text) — Multimodal processors, image inputs, vision language inference.
- [DOC: Docling documentation](https://docling-project.github.io/docling/) — Document parsing, layout, tables, OCR, structured representations.

### Interview question

Why can downsampling make an otherwise capable model miss a defect?

**A strong answer addresses:** Small details; spatial resolution; preprocessing.

Score 0–3 using the [shared interview rubric](../README.md#interview-rubric).

### Production exercise

Create a synthetic equipment-photo dataset with varying light, scale and text size, and compare preprocessing effects.

**Acceptance criteria:**

- Keep source and processed-image lineage.
- Evaluate quality by visual condition.

**Evidence to submit:**

- Versioned artifact or design specification.
- Baseline or hand-checkable fixture.
- Results or expected-results table including a failure case.
- Decision and limitations note.

**Resources:** Tiny/local model, synthetic media, or supplied recorded outputs/profiles; larger GPU or paid-provider runs are optional. Replay analysis cannot establish real hardware performance.

## M37-L04 — Ground and evaluate visual decisions

**Prerequisites:** [M37-L03](M37.md#m37-l03)

**Learning outcome:** Require visual claims to be supported by observable evidence.

**Topics:** visual hallucination; spatial reasoning; document VQA; evidence regions; robustness.

**Study estimate:** 1–2 hours guided study + 2–4 hours exercise. These are learner-effort estimates, not an implementation schedule.

### Primary readings

- [VISION: Hugging Face image text to text](https://huggingface.co/docs/transformers/main/en/tasks/image_text_to_text) — Multimodal processors, image inputs, vision language inference.
- [EVAL: OpenAI evaluation best practices](https://developers.openai.com/api/docs/guides/evaluation-best-practices) — Task-specific datasets, graders, human calibration, continuous evaluation.

### Interview question

How would you test whether a VLM reads a label or guesses from context?

**A strong answer addresses:** Counterfactual images; text perturbations; evidence regions.

Score 0–3 using the [shared interview rubric](../README.md#interview-rubric).

**Acceptance criteria:**

## Module completion gate

Submit all four lesson artifacts, answer the four interview questions, and explain one failure-and-recovery case. A reviewer checks acceptance criteria and labels results as designed, simulated, replayed or measured. A plan or replay is not proof of production performance.
