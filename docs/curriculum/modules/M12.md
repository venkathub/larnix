## M12-L01 — Budget the context window

**Delivery:** planned · full lesson contract: not_met · interaction: none · artifact: none

**Prerequisites:** [M10-L04](M10.md#m10-l04), [M11-L04](M11.md#m11-l04)

**Learning outcome:** Allocate context by utility and priority rather than arrival order.

**Topics:** system instructions; tool definitions; evidence selection; token budgets; attention limits.

**Study estimate:** 1–2 hours guided study + 2–3 hours exercise. These are learner-effort estimates, not an implementation schedule.

**Estimate basis:** Study budget the context window; build or analyze: Implement a context builder with reserved output capacity, ranked evidence slots and a visible token-budget manifest. Verify: Account for all token consumers. Stated prerequisites met; small local fixture or explicitly labeled replay; excludes large training runs and cloud provisioning. Confidence: low; editorial estimate, not learner-measured.

### Primary readings

- [CONTEXT: Anthropic context engineering](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents) — Context selection, compaction, long tasks, external memory.
- [CHAT: Hugging Face chat templates](https://huggingface.co/docs/transformers/main/en/chat_templating) — Role serialization, generation prompts, template compatibility.

### Interview question

Why can adding relevant documents still worsen the answer?

**A strong answer addresses:** Redundancy; distractions; position effects; budget.

Score 0–3 using the [shared interview rubric](../README.md#interview-rubric).

### Production exercise

Implement a context builder with reserved output capacity, ranked evidence slots and a visible token-budget manifest.

**Acceptance criteria:**

- Account for all token consumers.
- Test overflow with deterministic truncation rules.

**Evidence to submit:**

- Versioned artifact or design specification.
- Baseline or hand-checkable fixture.
- Results or expected-results table including a failure case.
- Decision and limitations note.

**Resources:** CPU/local fixtures or a mocked provider; live service use is optional.
