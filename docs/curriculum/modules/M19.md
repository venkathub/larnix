## M19-L01 — Choose deterministic orchestration

**Delivery:** planned · full lesson contract: not_met · interaction: none · artifact: none

**Prerequisites:** [M09-L04](M09.md#m09-l04), [M11-L04](M11.md#m11-l04)

**Learning outcome:** Start with the simplest control flow that meets the task.

**Topics:** workflow; routing; chaining; parallel branches; state machines.

**Study estimate:** 1–2 hours guided study + 2–3 hours exercise. These are uncalibrated learner-effort estimates, not measured timings or an implementation schedule.

### Primary readings

- [AGENT: Anthropic building effective agents](https://www.anthropic.com/engineering/building-effective-agents) — Workflow patterns, autonomy, tool design, complexity tradeoffs.

### Interview question

When is an agent unnecessary for a multi-step task?

**A strong answer addresses:** Predictable paths; auditability; bounded inputs.

Score 0–3 using the [shared interview rubric](../README.md#interview-rubric).

### Production exercise

Implement a deterministic equipment-return workflow with explicit decision branches and terminal states.

**Acceptance criteria:**

- Cover every terminal state.
- Compare complexity and failure behavior to an agent proposal.

**Evidence to submit:**

- Versioned artifact or design specification.
- Baseline or hand-checkable fixture.
- Results or expected-results table including a failure case.
- Decision and limitations note.

**Resources:** CPU/local fixtures or a mocked provider; live service use is optional.

## M19-L04 — Evaluate agency costs

**Delivery:** planned · full lesson contract: not_met · interaction: none · artifact: none

**Prerequisites:** [M19-L03](M19.md#m19-l03)

**Learning outcome:** Decide whether added autonomy improves outcomes enough to justify complexity.

**Topics:** task completion; trajectory quality; error accumulation; autonomy levels; baselines.

**Study estimate:** 1–2 hours guided study + 3–4 hours exercise. These are uncalibrated learner-effort estimates, not measured timings or an implementation schedule.

### Primary readings

- [AGENT: Anthropic building effective agents](https://www.anthropic.com/engineering/building-effective-agents) — Workflow patterns, autonomy, tool design, complexity tradeoffs.
- [TAU: tau-bench original paper](https://arxiv.org/abs/2406.12045) — Stateful tool-agent-user tasks and repeated reliability.

### Interview question

How would you demonstrate an agent outperforms a workflow?

**A strong answer addresses:** Matched tasks; failure severity; cost; human effort.

Score 0–3 using the [shared interview rubric](../README.md#interview-rubric).

**Acceptance criteria:**

- Include tasks requiring clarification.
- Compare errors, elapsed time and human interventions.

**Evidence to submit:**

- Versioned artifact or design specification.
- Baseline or hand-checkable fixture.
- Results or expected-results table including a failure case.
- Decision and limitations note.

**Resources:** CPU/local fixtures or a mocked provider; live service use is optional.
