# M29 — Deployment and delivery

[All modules](../INDEX.md) · [Learning path](../LEARNING_PATH.md) · [Source register](../SOURCES.md) · [Teaching design](../TEACHING_DESIGN.md)

**Status:** planned · **Depth:** core · **Track:** T5

**Entry prerequisites:** [M02-L04](M02.md#m02-l04), [M25-L04](M25.md#m25-l04), [M28-L04](M28.md#m28-l04)

8 lesson specifications follow. Each lesson will use a concrete problem, prediction, interactive explanation, worked example, inline checks and failure investigation before production and interview practice. Follow the teaching design for accessibility and original visual treatment. Delivery status is stated per lesson; a preview is not a completed lab. Complete the evidence package for each exercise; live deployment is not required. Later lessons may introduce an additional cross-module prerequisite.

## Module outcomes

- Specify a build that reproduces code, configuration and model dependencies.
- Place deterministic and probabilistic checks at appropriate release stages.
- Roll out code and model changes while preserving recoverability.
- Choose deployment complexity from workload and team needs.
- Reproduce a classical-model run from an immutable data version, transform pipeline and recorded configuration.
- Promote a tested model version and roll back without changing the meaning of its input features.
- Use one frozen transform-model pipeline in two scoring modes and explain their operational tradeoffs.
- Decide whether to investigate, retrain or roll back using drift alerts and delayed performance evidence.
